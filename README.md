# Shadat Hossain — Portfolio

Static portfolio for GitHub Pages.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Deploy
1. Create a GitHub repository.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch → main → /root**.
5. Save and wait for GitHub Pages to publish.

## Personalization
- Replace links/placeholders in `index.html`.
- Add project evidence/screenshots under `assets/`.
- Keep secrets, API keys and passwords out of this repository.
- The included CV is provided as a local download asset.
